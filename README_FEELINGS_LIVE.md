# Usly — Live Feelings

В этой версии «Чувства» работают как одно актуальное состояние каждого партнёра.
Истории чувств нет.

## Supabase

Выполни **только содержимое** файла:

`supabase/003_current_feelings.sql`

Он:
- удаляет старую `couple_feelings`, если она была создана по предыдущей версии;
- создаёт одну запись на пользователя в паре;
- включает RLS;
- включает Supabase Realtime для таблицы;
- разрешает менять только своё чувство;
- позволяет партнёру видеть актуальное чувство своей пары.

## Frontend

После SQL:

```bash
npm install
npm run dev
```

Проверь двумя аккаунтами:

1. Аккаунт A выбирает «Грустно».
2. Аккаунт B открывает главную или «Чувства».
3. У B должна автоматически появиться карточка «Партнёр сейчас → Грустно».
4. A меняет «Грустно» на «Скучаю».
5. B должен увидеть «Скучаю» без перезагрузки.

В базе при этом остаётся максимум одна запись на пользователя в каждой паре.
