# Usly v46 — block controls + richer couple calendar

## Changes
- Added per-space block visibility settings for the Home and Us sections.
- Home blocks can be hidden independently: partner feeling, couple note, latest photo.
- Us blocks can be hidden independently: stats, moments calendar, dates, achievements, gift wishlist, entertainment, compatibility, horoscope, secret room.
- Visibility preferences are stored locally per couple (`usly-blocks-<coupleId>`), so hiding a block does not alter shared data.
- Added different colored circular markers for intimacy calendar events and a small legend.
- Expanded achievements with 500/730/1000-day milestones, 25/50-photo milestones, and 25/50-wish milestones.
- Expanded date ideas and closeness questions with many additional prompts.
- Preserved the requested Us section order: stats → moments calendar → dates → achievements → gift wishlist → entertainment → compatibility → horoscope → secret room.
- Preserved the working real online/offline partner presence indicator and the full-bleed constellation treatment from v45.
