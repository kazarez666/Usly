# Nocturne constellation sources

The Nocturne theme uses real constellation star maps from Wikimedia Commons rather than hand-invented point layouts. The selected zodiac sign determines which source image is shown.

- Pisces: `ConstellationPisces.svg` by Dirk Hünniger — CC BY-SA 3.0 / GFDL.
- Taurus: `ConstellationTaurus.svg` by Dirk Hünniger — CC BY-SA 3.0 / GFDL.
- Gemini: `ConstellationGemini.svg` by Dirk Hünniger — CC BY-SA 3.0 / GFDL.
- Cancer: `ConstellationCancer.svg` by Dirk Hünniger — CC BY-SA 3.0 / GFDL.
- Leo: `ConstellationLeo.svg` by Dirk Hünniger — CC BY-SA 3.0 / GFDL.
- Virgo: `ConstellationVirgo.svg` by Dirk Hünniger — CC BY-SA 3.0 / GFDL.
- Libra: `Libra constellation map.svg` — Wikimedia Commons, CC BY-SA 3.0.
- Scorpius: `Scorpius.svg` by Maxmath12 — CC0.
- Aries, Sagittarius, Capricornus: Field Book of the Stars SVG maps by Goran tek-en — CC BY-SA 4.0.
- Aquarius: `Field Book of the Stars-103-Aquarius.svg` by Goran tek-en — CC BY-SA 4.0.

The app applies a visual monochrome/glow treatment to these source maps for the Nocturne theme.
